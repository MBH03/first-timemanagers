Build it once for the work you do over and over.

If you're re-explaining the same context to AI every single time, that's a setup problem, not a prompting problem. Most tools let you save a standing "project" or "agent," a place that already knows your team, your format, and your voice, so you're not rebuilding the prompt from scratch every week.

Set it up once with real detail. What comes out is only as good as what you put in at the start.

ELT status updates
Load in your team's goals, current projects, and last month's update as examples. Then each week you're feeding it bullet points, not writing the summary from a blank page.
Customer update emails
Give it two or three past emails you were happy with, plus the tone you want (direct, warm, no corporate padding). It'll hold that voice far more consistently than you rewriting it fresh each time.
Reviewing reports
Tell it what you're actually checking for, numbers that don't reconcile, missing context, claims without evidence, and have it flag those first. You still read the whole thing, it just tells you where to look hardest.
Setting This Up, Step by Step

Both Claude and ChatGPT let you build a standing workspace that holds context between conversations. The setup is a few minutes once, and it pays off every time after.

In Claude: create a Project
Click "Projects" in the sidebar, then "New project." Name it for the recurring task, "ELT Status Update" or "Customer Emails," not just "Work." Open Project Knowledge and upload or paste the reference material: last month's update, your team's goals doc, two or three past emails you were happy with. Add custom instructions in the project settings, the tone you want, the format, anything it should never do (no corporate padding, no exclamation points, whatever's true for you). Every new chat inside that project automatically has all of it loaded, so you're not re-pasting context each time.
In ChatGPT: create a Project or a Custom GPT
Click "Projects" in the sidebar and create one the same way, name it specifically, add files to it (past examples, team goals, style notes), and set project instructions that describe the tone and format you want. If you want something more reusable across your whole team, build a Custom GPT instead: go to "Explore GPTs," then "Create," and configure it with instructions and reference files the same way. A Custom GPT can be shared with a link, a Project is yours alone.
Load the reference material with real detail
Don't just say "write like me." Paste in two or three actual examples of the output done well, plus one you'd consider a miss and why. Specific beats descriptive every time, the model learns your voice from examples far better than from an adjective.
Use it, then correct it back into the project
The first few outputs won't be perfect. When you edit one, save the corrected version back into the project's files or notes, "here's the version I actually sent, use this as the new example." The project gets better each time you do this, instead of you making the same correction over and over in every new chat.
Setting one up

Give it your team's context once: who's on it, what you're working on, the format you want things in, and two or three examples of the output done well. From then on, each new request only needs what's different this time.

The point isn't to remove yourself from the work. It's to stop spending the first ten minutes of every request re-explaining things it should already know.
